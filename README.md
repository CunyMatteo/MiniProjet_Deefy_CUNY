Deefy est une application web de gestion de playlists audio développée en PHP dans le cadre du BUT Informatique à l'IUT Nancy Charlemagne.
Elle permet de lister les playlists existantes, consulter leur contenu, créer de nouvelles playlists, gérer une playlist courante en session et ajouter des pistes audio au format MP3.

Ce projet était à réaliser en binôme, mais par choix j'ai décidé de le faire en monôme.

Lien vers l'application en ligne : https://webetu.iutnc.univ-lorraine.fr/www/e7855u/deefy/
